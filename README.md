# 🛒 Superstore Sales Analysis & Dashboard

A complete data analytics project exploring Superstore retail sales data using Python and Power BI.  
This project covers data cleaning, exploratory analysis, visualization, and business insights to support data-driven decision-making.

---

## 📌 Project Overview
This project analyzes Superstore sales transactions to identify:
- Profit and loss patterns  
- Regional and category-level performance  
- Customer segment trends  
- Discount impact on profitability  
- Opportunities for business optimization
